# Game Dev Resource Sites

Holden's go-to sites (shared during [[Paper Plane Toss]], 2026-10-03), to check alongside Poly Pizza and the AssetLibrary.

- **UI:** https://ui-resources.com/, https://ui8.net/
- **Sound:** https://www.zapsplat.com/ (for the later sound-effects pass)
- **3D:**
  - https://sketchfab.com/tags/glb
  - https://pixabay.com/3d-models/ (Pixabay also has images, sounds and music)
  - https://blendswap.com/
  - https://polyhaven.com/
- **Tools:** https://low-poly.com/tools/reduce (mesh reducer)
- **Animation:** https://www.mixamo.com/
- **Roblox:** https://rotrends.com/ (trends and stats), https://builtbybit.com/resources/roblox/ (marketplace)

Check every asset's licence: credit CC-BY, and ask before using paid or no-commercial-use items. The [[Art Direction Feedback]] rules still apply.
