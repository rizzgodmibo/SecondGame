# Titles, Descriptions and Tags (Genre)

## TL;DR
- **Title = brand + genre keyword, ideally ≤30 characters** (hard cap ⚠️ 50). Example: "Fishing Tycoon", "Evolution Simulator". Keep the core name **stable**: Roblox warns that frequent renames make you harder to find.
- Update tags like **`[UPD]`, `[NEW]`, `[🎃EVENT]`, `[x2]`** at the front of the title are a platform-wide convention for returning players. Use them **only while true** (about 1–2 weeks after an update) and use **1–2 emojis max**. Spammy repetition gets you demoted (official).
- **Description:** the first **~160 characters** are the hook. They show on mobile before "expand" and in Google snippets. Use: hook → recent update (short) → core loop bullets → devices, codes and a mini-FAQ. The limit is **1,000 characters** (official docs).
- **Hashtags and keyword lists are useless.** They are "unused in our ranking algorithms" (official) and keyword stuffing gets you demoted. Write natural sentences that include the words players actually search for (Search is now semantic).
- **Genre and subgenre:** pick the one that matches the core loop. It drives **genre-specific Charts sorts** and player expectations, but it is **not an RFY ranking factor**. You can change it only **once every 3 months**.
- **Never lead with giveaways or Robux** ("FREE ROBUX", "UGC giveaway"). Official: reduced exposure.

## Details

### Title conventions
| Pattern | Example | Use when |
|---|---|---|
| `Brand Genre` | "Pet Simulator 99", "Restaurant Tycoon 3" | Default. Genre words help search and set expectations |
| `[UPD #] Brand` / `[🎃] Brand` | "[UPD 🌋] Volcano Obby" | 7–14 days after a content update, for returning players scanning Continue/Charts ⚠️ verify: no official data on CTR lift |
| `Verb + noun` hook names | "Grow a Garden", "Steal a Brainrot", "Dress to Impress" | Trend-native, describe the action in 2–4 words |
| Avoid | "OBBY OBBY OBBY", "🐒🐬Ev🌍lution🌷", "FREE UGC", other games' names | Official examples of spam that gets demoted |

Rules:
- Length: aim for **≤30 characters**. Longer titles truncate on phone tiles. The commonly cited hard cap is 50 characters ⚠️ verify: no official doc states the max.
- Put the **distinctive word first** so it survives truncation.
- Emojis: "one or two well-placed emojis isn't harmful" (official). Place them at the start or end, never inside words.
- Sequels and version numbers ("2", "99") signal an established brand. Use them only if the game really continues an IP you own.
- Localise the title in the localization tools for the top markets (non-English DAU is large). See [[Genre-Positioning]].
- Do not use another game's name or IP. It is non-unique metadata (de-prioritised) and an IP risk.

### Description structure (official experimental guide, 1,000-character budget)
| Block | Chars (target) | Content |
|---|---|---|
| **Hook** | ≤160 | Name + genre + most unique feature + main objective. Example: "X is a fast-paced tower defense game to build up your fortress and fend off hordes of enemies. Can you survive all 500 levels?" |
| **Recent update** (optional) | ≤120 | "🚨 SEASON 9 is here! New DANGER cosmetic set…" Keep it short. It pushes the main content down. |
| **Main content** | 300–450 | 4–6 emoji bullets of mechanics and selling points (official example: "🐟 500+ different fish to catch") |
| **Additional** | ≤250 | Devices (Desktop/Mobile/Tablet/Console), 1 active code, 1–3 FAQ lines |
| Do NOT include | — | Hashtags, tag lists, controls (teach controls in-game), off-platform links outside the official social-links feature |

The general metadata best practices (publish docs):
- First sentence summarises the game.
- Include *relevant* keywords naturally (sheriff, robbers, jail…).
- No keyword spam such as listing other games.
- The description must be appropriate for all ages.

### SEO for Roblox Search and Google
- Roblox Search: relevance to the query plus **semantic search in all supported languages** ("food games" finds cooking games). Matching on title and description text matters, as does using the genre nouns players type ("tycoon", "obby", "tower defense", "horror", "roleplay").
- An exact title query gives a large hero tile; **search ads display right after it**. Competitors can buy your name as a keyword, but relevance is factored into the auction. See [[Sponsored-Ads-And-Paid-Acquisition]].
- Google: the first 160 characters become the snippet. Top games get "millions of impressions a month on Google" (official). Wikis and copycats can outrank you, so use the full brand name in the hook.
- Use the **social links** feature (official) for Discord, YouTube, X and Guilded instead of pasting URLs in the description.

### Genre and subgenre settings (official 2026 list)
Action (Battlegrounds & Fighting, Music & Rhythm, Open World Action) · Adventure (Exploration, Scavenger Hunt, Story) · Education · Entertainment (Music & Audio, Showcase & Hub, Video) · Obby & Platformer (Classic, Runner, Tower) · Party & Casual (Childhood Game, Coloring & Drawing, Minigame, Quiz) · Puzzle (Escape Room, Match & Merge, Word) · RPG (Action, Open World & Survival, Turn-based) · Roleplay & Avatar Sim (Animal Sim, Dress Up, Life, Morph Roleplay, Pet Care) · Shooter (Battle Royale, Deathmatch, PvE) · Shopping (Avatar Shopping) · Simulation (Idle, Incremental Simulator, Physics Sim, Sandbox, Tycoon, Vehicle Sim) · Social · Sports & Racing (Racing, Sports) · Strategy (Board & Card Games, Tower Defense) · Survival (1 vs All, Escape) · Utility & Other.
- Choose based on the **primary purpose / core loop**. Set it **only once you are confident**, because it locks for 3 months. Roblox may re-classify an inaccurate genre (email notice; one appeal only).
- Genre changes take a few days to reach Charts genre sorts.
- Under-served genres (RPG, strategy, puzzle, shooter for older players) are explicitly sought for **Standout Games** curation.

### Policy rules
- No misleading metadata (title, description or thumbnail must match the game). Otherwise reduced exposure and lower search ranking.
- No giveaway-led or monetary-reward metadata.
- No repeated words and no irrelevant keywords.
- Codes in the description are fine. Rewards must not require off-platform actions that violate the Community Standards ⚠️ verify: current policy on "follow us on X for code".
- Paid brand integrations are **ads** and must be registered and disclosed (Independent Advertising Policy update 2026-05-04). See [[Influencer-Coverage]].

## Checklist
- [ ] Title ≤30 characters, genre keyword included, 0–2 emojis, unique.
- [ ] Update tag added on update day and removed after about 14 days.
- [ ] Description hook ≤160 characters with name + genre + unique hook + goal.
- [ ] Bullets cover core loop, social, progression and update cadence. Devices listed. One code.
- [ ] No hashtags, keyword lists, controls or other games' names.
- [ ] Genre and subgenre set to the core loop. Calendar reminder for the 3-month lock.
- [ ] Title and description localised for the top 5 player locales.
- [ ] Social links configured.

## Pitfalls
- Renaming every update ("Pet Sim → Pet Sim X → Pet Legends"). Returning users can't find you, and search history resets.
- Leaving "[UPD]" on permanently. It stops signalling anything and looks stale.
- Keyword-stuffed descriptions copied from 2018-era games. These get demoted.
- Choosing a trendier genre than the game really is. Mismatch causes bounces, which hurt RFY.
- A description that only serves returning players (patch notes). New players bounce.
