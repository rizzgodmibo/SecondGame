# X Reference: Character Animation

11 posts from `#RobloxAnimation min_faves:300` (2026-10-04), plus animation tooling. Part of [[X-Reference-Library]].
Most of that hashtag's top posts are comedy shorts and fan animation; this note keeps the ones useful for making games.

## TL;DR
- **Animation packs are a big UGC category:** R6 Modernized (6k likes), reanimated walk/run, themed packs. Players care
  how their avatar moves, so a game's default animations are part of its feel.
- **Comedy timing gets shared:** the top clips (7k–15k likes) are short, exaggerated character-acting gags. For a
  young-teen game, the same squash, anticipation and overshoot belongs in idle emotes, win poses and fail reactions.
- **Tooling:** RoRigged (easier rigging in Studio), Motor6D ⇆ AnimationConstraint conversion with pivot mirroring, and a
  Blender-driven rig concept. All unevaluated; see [[Animation-Rigging-And-IK]] for the existing workflow.
